# 水彩插图

三张插图来自项目所有者上传的原始 PNG；仅缩放、编码为 WebP，保留 2:1 完整构图，无重绘或内容替换。

- `kazoku.webp`：家族围坐桌旁
- `ai.webp`：双手托着爱心
- `jiyuu.webp`：鸟从打开的鸟笼飞向天空

尺寸统一为 960 × 480。插图仅用于词条详情页并立即加载；目录页保持纯文字卡片。资源相对 ES 模块解析以兼容 GitHub Pages 子路径，并预留固定尺寸以避免布局跳动。

## 首页装饰

`cover-book.webp` 是为本站新生成的透明背景水彩小景：翻开的书、枝叶和铅笔。尺寸 720 × 480，仅用于首页，不属于上述三张用户原画。装饰图片使用空替代文本，不影响标题和按钮的可访问名称。
